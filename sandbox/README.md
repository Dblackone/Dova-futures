# sandbox/ — Session Scratch Space (gitignored)

Everything in this folder except this README is **ignored by git** and will
never be committed. Use it for:

- experiments and throwaway prototypes
- generated intermediates (test renders, temp PDFs, scratch scripts)
- anything you are not yet sure belongs in the repository

When something in here proves worth keeping, move it to its proper home (your
workspace's `drafts/`, your declared code paths) and commit it on your session
branch. Full workflow: `governance/collaboration.md`.

The folder's contents live only in your session's container/clone — assume
anything left here is gone when the session ends.
