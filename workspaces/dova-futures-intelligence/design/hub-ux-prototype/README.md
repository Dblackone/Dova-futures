# DOVA Hub UX prototype

This is the approved design reference captured before production development.
It includes desktop and mobile layouts for the Hub, project workspace, files,
OneDrive library, approvals, activity, settings, and DOVA Intelligence-facing
surfaces.

- Local entry: `index.html`
- Canva edit: https://www.canva.com/d/c5GaqcOFGY-9-7k
- Canva view: https://www.canva.com/d/J9qIz_7ZSGqz59N

This folder is design-only. It does not authenticate, connect to OneDrive,
write documents, call OpenAI, or implement DOVA Intelligence. The production
read-only overview remains in the repository-level `hub/` folder.
