# DOVA Futures portable brand export

This folder contains `DOVA-Futures-Brand-Design-System-Pack-2026-09-22.zip`.
It is the portable handoff for another Codex project, app or website.

The archive contains the design-system tokens, canonical SVG sources, the
principal-approved logo placement pack, `logo-manifest.json`, and the placement
guide. Copy the `design-system/` contents into the consuming project's shared
brand/design-system folder, or copy the included `codex-skill/` folder to
`.agents/skills/dova-company-brand/` when the consuming project uses Codex
skills.

The files are the current working brand system. The PNG logo files have opaque
backgrounds and are not transparent vector masters. Keep the current letterhead
SVG for existing document templates. Revalidate the selected variant against
the consuming project's background and final crop before publishing.
