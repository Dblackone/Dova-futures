# DOVA Futures logo variations

This folder is the design system's working logo pack for **DOVA FUTURES
LIMITED**. Use `logo-manifest.json` as the machine-readable source for choosing
a variant. The human placement guide is in the design-system root at
`logo-usage.md`.

The pack preserves the approved three-building mark and condensed name lockup,
then adapts it for wide, square, symbol-only, wordmark and monochrome surfaces.
The primary horizontal pair is preferred for wide layouts. The stacked pair is
for square placements. The symbol pair is for small avatars and icon-like
placements. The wordmark is for narrow name-led placements.

These are optimised opaque RGB PNG exports. They are suitable for digital review
and ordinary digital use, but they are not transparent overlays or vector
production masters. Keep the existing letterhead SVG for current templates when
the services descriptor `DESIGNERS · BUILDERS · DEVELOPERS` is required.

The light stacked review raster (`03-square-stacked-green-on-white.png`) retains
a faint line above the right tower. Use the dark stacked version until a cleaned
light export is approved.
